# Лабораторная работа — Границы и контуры объектов

Выделение границ **Sobel / Scharr / Canny**, морфологическая очистка масок,
поиск контуров, фильтрация объектов по площади и вывод их **количества на кадр**.
Реализованы два интерфейса: **CLI** (`cli.py`) и **GUI** (`gui.py`, tkinter).

## Возможности

- источники: встроенные демо scikit-image (`coins`, `page`, `camera`, `astronaut`) —
  офлайн и одинаковые у всех; а также свои файлы и целые папки;
- границы: Sobel и Scharr (порог = доля от максимума магнитуды градиента),
  Canny (σ гауссова сглаживания + гистерезис low/high);
- очистка масок морфологией: `closing` / `opening` / `both` / `none`,
  структурный элемент `disk(r)`, заливка дыр;
- контуры внешних объектов (OpenCV, `RETR_EXTERNAL`) и фильтр по площади
  `[min_area, max_area]` (px), подсчёт объектов на кадр;
- оценка шума «до/после» очистки: число связных компонент в маске и доля
  шумовых пикселей, график `noise_compare.png` (в GUI — кнопка «График шума»);
- сохранение «до/после»: `before/original.png`, `after/edges_*.png`,
  `after/mask_*.png`, `after/overlay_*.png`, сводный `panel.png`;
  параметры и счётчики — в `results.json`.

Ни один параметр не «зашит»: всё задаётся аргументами CLI или полями GUI
(значения по умолчанию — в `pipeline.Params`).

## Установка

Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск CLI

```bash
python cli.py --source coins                                    # демо coins, все методы
python cli.py --source coins -m canny --canny-sigma 3 --min-area 200
python cli.py --source camera --out results/camera              # другое демо
python cli.py --source path/to/photo.png                        # свой файл
python cli.py --source path/to/folder --out results/scan        # вся папка: счёт на каждый кадр
python cli.py --list                                            # доступные демо
```

Количество объектов печатается в консоль (по каждому кадру) и сохраняется
в `results.json`. Список всех параметров: `python cli.py --help`.

## Запуск GUI

```bash
python gui.py
```

Слева — те же параметры, что и в CLI (методы, пороги, морфология, фильтр по
площади); сверху — выбор источника (демо-кнопки или «Открыть файл…»).
«Запустить» строит панель «до/после», «График шума» открывает сравнение
шума в масках до/после очистки, «Сохранить результаты» пишет папку
`results/<имя>/`.

## Значения параметров по умолчанию (обоснование)

| Параметр | Значение | Почему так |
|---|---|---|
| `sobel_thresh`, `scharr_thresh` | 0.10 | порог задан как доля от максимума магнитуды — он масштабируется к яркости кадра; 0.10 отделяет сильные рёбра монет от гладкого фона |
| `canny_sigma` | 2.0 | сглаживает шум и текстуру монет, сохраняя рёбра; меньше — шум, больше — контуры разваливаются |
| `canny_low/high` | 0.10 / 0.25 | гистерезис: слабые рёбра продолжаются только от сильных; выбрано отношение ≈ 1:2.5 |
| `morph_op` | closing | замыкание сшивает разрывы контуров толщиной 1–2 px, чтобы объекты можно было залить и посчитать |
| `morph_size` | 3 | `disk(3)` закрывает типовые разрывы, но не склеивает соседние монеты |
| `morph_iters` | 1 | одного прохода достаточно для монет; больше — риск склейки |
| `fill_holes` | true | подсчёт идёт по площади сплошных объектов, а не по контурным кольцам |
| `min_area` | 100 px | отсекает шумовые пятна; монеты на кадре 303×384 имеют площадь ≥ 1000 px |
| `max_area` | 0 (нет) | по умолчанию не ограничивает; можно задать, чтобы отбрасывать слипшиеся «парные» объекты |

## Результаты

`results/coins/` — папка «до/после» для `data.coins`:
`before/original.png`, `after/*`, `panel.png`, `noise_compare.png`, `results.json`.

Проверка на `coins`: **22 объекта всеми тремя методами**. Контрольная
пороговая сегментация (Отсу + заливка) даёт 24 связные области, одна из
которых площадью 9437 px — это **пара соприкасающихся монет**: физически
в кадре 24 монеты, но контуры двух соприкасающихся пар после замыкания и
заливки объединяются в один объект (видно на `panel.png` слева внизу).
Разделение слипшихся объектов — marker-based watershed, выходит за рамки
задания.

График `noise_compare.png` показывает эффект морфологической очистки:
число компонент в маске падает с 254/256/75 (sobel/scharr/canny) до
58/68/24, а доля шумовых пикселей (компоненты < 100 px) — с 3.2/3.1/26.5%
до 0.4/0.4/0.0%.

Подробное обоснование выбора методов и параметров — в `REPORT.md`.
